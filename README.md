# AUTOMETA

**A cross-app automation platform with Cloud and On-device execution.** Trigger → Conditions → Actions, built with Flutter (app) and Node (Cloud backend in `server/`).

**Cloud is the recommended, default execution mode**: Cloud automations run on the Autometa backend and keep running when the app is closed or the phone is offline. **On-device** execution remains for eligible local automations and is subject to Android's background rules. See [docs/EXECUTION.md](docs/EXECUTION.md).

Create scheduled workflows ("every day at 07:00 → WhatsApp → *Good morning Dad*"), branch with IF/ELSE, generate text with AI, call HTTP APIs and webhooks, and watch every run in an honest activity log.

## Honesty rules (enforced in code)

* A personal-account WhatsApp run is reported as **“Handed to WhatsApp — you tap Send”**, never “Sent” (`whatsapp.handed_to_user`).
* Dry runs are recorded and displayed as **SIMULATION**.
* A connection is only **Connected** after a live check (`Integration.check()`); stored tokens are not proof.
* On-device AI output is tagged **LOCAL TEMPLATES**, not “AI”.
* Missed runs older than 6 h are recorded as **SKIPPED**, not sent late.

## Setup

Requirements: Flutter ≥ 3.29 (Dart ≥ 3.7), Android SDK 35, JDK 17.

```bash
flutter pub get
flutter test                 # engine, scheduler, DB, WhatsApp, AI parser…
flutter run                  # device or emulator
flutter build apk --release  # configure signing first (see below)
```

`android/local.properties` is generated by Flutter. For release signing, create `android/key.properties` + keystore (both git-ignored) and wire a `signingConfig` in `android/app/build.gradle.kts`.

### First run
Welcome → choose WhatsApp / AI → pick **Personal** or **Business** and enter Dad’s number (optional) → enable **Morning Dad**, then Evening/Night Dad.

### WhatsApp Business
Connections → WhatsApp → Business: enter the **Phone Number ID**, a **system-user access token** (stored in Android Keystore-backed secure storage) and the Graph API version (default `v26.0`). See [docs/WHATSAPP.md](docs/WHATSAPP.md).

### AI
Settings → AI Provider. Keys go to secure storage only and never appear in logs (`Logger.scrub`).

## Background execution
See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#android-background-execution). Short version: AlarmManager exact alarms + reboot restore + a maintenance wake. Android can still delay alarms (Doze, battery optimisation, OEM killers); the app says so and offers the battery-optimisation exemption.

## Icon
A spec-compliant **placeholder** vector icon ships in `android/app/src/main/res/drawable/ic_launcher_*.xml` (adaptive + monochrome). To use your own artwork, see [docs/ICON.md](docs/ICON.md).
